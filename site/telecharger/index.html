Ouvrir app.passeryder.fr
  1. Ouvre app.passeryder.fr dans Safari.
  2. Touche Partager (le carré avec une flèche vers le haut).
  3. Choisis « Sur l’écran d’accueil », puis Ajouter.

Préviens-moi quand ça sort sur iPhone

Un seul email, avec un lien pour te désinscrire. Adresse effacée 90 jours après l’envoi. Tu as un compte ? Active-le dans l’appli : Paramètres › Notifications.
